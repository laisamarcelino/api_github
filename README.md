# GitHub Finder 🔎 (em desenvolvimento)

Projeto construído com **React**, **TypeScript** e **Vite** que permite buscar usuários do GitHub e visualizar informações básicas como foto, localização, seguidores, seguindo e projetos em destaque.

Os dados são obtidos diretamente da [API pública do GitHub](https://api.github.com/).

## 🚀 Tecnologias utilizadas

- [React](https://reactjs.org/)
- [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vitejs.dev/)
- [API do GitHub](https://docs.github.com/en/rest)


## 📦 Instalação e execução

```bash
# Clone o repositório
git clone https://github.com/seu-usuario/github-finder.git

# Acesse o diretório
cd github-finder

# Instale as dependências
npm install

# Execute o projeto em ambiente de desenvolvimento
npm run dev
